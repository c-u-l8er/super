# Super prototype → usable development MVP

Audited 2026-09-07 against `site/app-prototype.html`, current `cockpit/ui`,
`cockpit/src/bots.rs`, `Ampd.Projection.operator/0`, and `Ampd.CommandSpec`.
The prototype is a simulated design reference. Its numbers and bot grants are
not live app records. Existing local modifications were retained.

## Acceptance target

Use Super to develop Super: select its repository and workspace, create a goal,
choose a persistent planning or implementation bot, delegate bounded development
work, observe progress and blockers, review a real diff and validation results,
accept or reject the change, and recover that same work after restart.

The app currently supports conversation and reviewed setup proposals. This pass
improves that usable surface; the full development cycle still needs the runtime
and editor work below. A worker assignment does not start coding.

## This pass

summary statistics. Profiles and groups are local presentation records. Bot pages
explicitly identify the runtime delegation gap. This pass does not expose a fake
Delegate button, fabricate agent activity, or turn profiles into runtime actors.

No runtime stores, grants, command allowlists, or authority rules were modified.
Graphonomous tools were not available in this session; the existing task notes,
repository instructions and current source supplied continuity.
